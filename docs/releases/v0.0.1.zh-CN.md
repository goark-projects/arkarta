# Arkarta v0.0.1 发版说明

语言：[English](v0.0.1.md) | 简体中文

发布日期：2026-08-27  
模块：`goark.dev/arkarta`  
许可证：Apache License 2.0

## 摘要

`v0.0.1` 是 Arkarta 的第一个公开版本。它为 Goark 企业级 Web 标准固定第一版基线，覆盖 Servlet 风格容器契约和上层 Web 开发栈。

这个版本是标准基线，不是生产 Web 容器。Goark Tomcat、Goark Jetty 和高性能原生容器应实现本模块，并通过 Arkarta TCK 证明兼容性。

## 安装

```shell
go get goark.dev/arkarta@v0.0.1
```

## 本版包含

### Servlet 标准

- Core 请求和响应契约。
- Handler、Servlet、Filter、Chain、WebApp、生命周期、分发和错误语义。
- Servlet 路径映射、RequestDispatcher、错误页和 panic 恢复。
- `net/http` 适配器和最小参考容器。
- Container SPI 和动态注册元数据。
- Session、Multipart、Async/Stream、Upgrade、Native I/O 和 Servlet 声明式安全等 Optional Profile。
- Servlet Core 与各 Profile 的 TCK 入口。

### WebSocket 标准

- RFC 6455 握手和帧层。
- 子协议协商。
- permessage-deflate 协商。
- Endpoint、Session、Message、Close Status、Connection SPI 和服务循环。
- Servlet Upgrade 适配，包含 HTTP 101 写出、帧连接适配和 Endpoint 辅助。
- WebSocket 握手、端点生命周期、压缩和帧层 TCK。

### JSON 标准

- `json.Codec`、流式 Encoder、流式 Decoder 契约。
- `encoding/json` 默认实现。
- `json/sonic` 高性能实现。
- 输入大小限制、未知字段控制、数字精度模式、HTML 转义和缩进控制。
- `json/tck` Codec 兼容性测试。

### Validation 标准

- 结构体标签字段校验。
- 嵌套结构体和切片校验。
- 通过 `arkarta-groups` 支持校验分组。
- 消息解析器。
- 对象级约束。
- 内置约束：`required`、`notblank`、`min`、`max`、`len`、`email`、`oneof`、`regexp`、`url`、`uuid`、`gt`、`gte`、`lt`、`lte`、`contains`、`startswith`、`endswith`。
- 自定义约束和聚合校验错误。

### Web MVC/REST 层

- 方法路由和路径变量。
- 路由分组和分组级拦截器。
- `GET` 自动支持 `HEAD`。
- 自动 `OPTIONS` 和稳定 `Allow`。
- JSON、Form、Multipart、Path、Query、Header、Cookie 绑定辅助。
- 参数转换辅助。
- 统一 `Result`、错误映射器、响应增强和拦截器链。
- `web/tck` 兼容性测试。

### 根 Security 契约

- Principal 和 Authority。
- Authentication 和 Credential。
- AuthenticationManager。
- 通过 `context.Context` 传播 SecurityContext。
- Authorizer 和授权决策。

## 兼容性与验证

本版本发布前使用以下门禁验证：

```shell
go test ./...
go test -race ./...
go vet ./...
git diff --check
gofmt -l .
```

`gofmt -l .` 必须无输出。

容器实现只应运行并声明自己通过的 Profile 对应 TCK：

- `servlet/tck`
- `web/tck`
- `websocket/tck`
- `json/tck`

## 不包含

- Goark Tomcat、Goark Jetty 或任何生产 Web 容器。
- 与 `jakarta.servlet` 或 `javax.servlet` 的 Java 命名空间兼容。
- JSP、JSTL、Expression Language、WAR/EAR 打包、Java 注解、运行时 classpath 扫描或 Java 式继承 API。
- OAuth2/OIDC/JWT provider、CSRF、CORS、密码存储或策略引擎。这些属于更高层安全实现。

## 发布范围

`v0.0.1` 是预览基线。公共 API 已按标准设计，但在 `v0.1.0` 前，如果标准质量需要，仍允许必要的源码不兼容修正。
