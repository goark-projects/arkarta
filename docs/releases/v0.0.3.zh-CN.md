# Arkarta 0.0.3

[English](https://github.com/goark-projects/arkarta/blob/v0.0.3/docs/releases/v0.0.3.md) | 中文

发布日期：2026 年 9 月 7 日

Arkarta 0.0.3 是 Go 原生企业级 Web 标准的维护版本。它在不改变 0.0.2
公共契约的前提下，加强了请求限制语义、源码组织和跨平台发布门禁。

精简版本历史见[变更日志](https://github.com/goark-projects/arkarta/blob/v0.0.3/CHANGELOG.zh-CN.md#003---2026-09-06)。

## :star: 版本亮点

- 当配置限制为零时，保持 URL 编码表单体不受大小限制。
- 将 Servlet、Session 和 Web 标准整理为职责更集中的源码文件。
- 为 `net/http` 参考 Server 提供安全的请求头、空闲连接和头部大小默认值，且不限制流式响应。
- 要求 Go 1.26，并在 CI 中验证 Linux、Windows 和 macOS。

## :package: 安装

```bash
go get goark.dev/arkarta@v0.0.3
```

## :information_source: 兼容性

- 模块要求 Go 1.26 或更高版本。
- 相对于 0.0.2，没有引入有意的公共 API 不兼容变更。
- 容器仍只能声明其已通过对应 TCK 的 Arkarta Profile。

## :white_check_mark: 验证

候选版本已在 Windows Go 1.26 和 Debian Linux Go 1.27 上通过模块校验、测试、
vet 和 race 测试。CI 会在 Linux、Windows 和 macOS 上重复执行格式、模块、
测试、vet 和 race 门禁。
