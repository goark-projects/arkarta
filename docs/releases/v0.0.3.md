# Arkarta 0.0.3

English | [中文](https://github.com/goark-projects/arkarta/blob/v0.0.3/docs/releases/v0.0.3.zh-CN.md)

Release date: September 7, 2026

Arkarta 0.0.3 is a maintenance release of the Go-native enterprise Web
standard. It strengthens request-limit correctness, source organization, and
cross-platform release gates without changing the public contract introduced
by 0.0.2.

See the [changelog](https://github.com/goark-projects/arkarta/blob/v0.0.3/CHANGELOG.md#003---2026-09-06)
for the concise version history.

## :star: Highlights

- Preserve unlimited URL-encoded form bodies when the configured limit is zero.
- Keep Servlet, Session, and Web standards in smaller responsibility-focused
  source files.
- Apply safe request-header, idle-connection, and header-size defaults to the
  `net/http` reference server without limiting streaming responses.
- Require Go 1.26 and validate Linux, Windows, and macOS in CI.

## :package: Installation

```bash
go get goark.dev/arkarta@v0.0.3
```

## :information_source: Compatibility

- The module requires Go 1.26 or later.
- No intentional public API incompatibility is introduced relative to 0.0.2.
- Containers must continue to claim only Arkarta profiles covered by their
  passing TCK runs.

## :white_check_mark: Verification

The release candidate passed module verification, tests, vet, and race tests
with Go 1.26 on Windows and Go 1.27 on Debian Linux. CI repeats formatting,
module, test, vet, and race gates across Linux, Windows, and macOS.
